## Artistic Statement
### Design Choices
- Intended on learning dialogue systems and how to use choices in those systems as a form of puzzle, focused a lot on having the cat become the anchor for the puzzle to level 2. Some of the permanent choices you make has a clue about your main character's identity that you won't get by choosing any other option.

### Game Assets & Placeholders (SPOILERS)
- **Main Character - Priest Intended to be the heroine of the story**
- **Premade environment tilemaps used to depict the forgotten civilization of the main character**
- **Cat, a shift into the absurd with the cat being able to communicate to the player.**
